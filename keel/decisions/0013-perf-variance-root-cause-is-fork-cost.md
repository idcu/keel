# 0013 性能抖动的根因是 fork 成本，不是判据；先量化再谈优化

> 接续 [ADR 0008](0008-batch-fork-and-time-budget.md)（把 per-file fork 批量化）。
> 本篇回答 0008 留下的那个问题：**为什么优化过了，耗时仍散布 27–201s（7 倍）**。

## 背景

ADR 0008 把 lint 从 319s 降到 97s，手段是批量化。但 2026-10-04 连续采样出现
**27s / 31s / 137s / 145s / 178s / 184s / 201s** 的散布，同代码同机器同文档数。

`LINT_SECONDS=300` 注释里的"97–193s"依据已与现实脱节（最差 201s，余量只剩 1.5 倍）。
`NOW.md` 连续两轮把它登记为"未查明"。本轮用**分段打点 + 微基准**查清了。

## 决定

**根因是 Windows/Git Bash 上单次 fork 极贵，不是判据复杂，也不是并发。**
故：**不优化判据、不改 `LINT_SECONDS`，先把测量方法与基线写进真源。**

微基准（`N=20`，Git Bash）：纯赋值 **~0ms** · `$(printf)` ~50ms ·
`$(basename)` ~150ms · `date -d` **~250ms**。

分段打点（142s 那次）：段 3 值域 **41s**、段 4 命名 **24s**、段 11 坑条目 **24s**、
段 10 陈旧 **10s**——**没有单点热点，是 per-file 成本被乘以文件数**。

### 关键发现：**`$(纯 shell 函数)` 本身就是一个 fork**（微基准 `N=30`）

`v=$(pure_shell_fn)` **~100ms**，即使函数体内一个外部命令都没有；
直接调用（不取返回值）或用全局变量回传都是 **~0ms**。

**这是 ADR 0008 漏掉的一层**：它消掉了 `wc`/`awk`/`grep` 这类真外部命令的
per-file 调用（那部分确实做到了），但 `st=$(fmq …)` 这种**取返回值的写法
自带一个 fork 子 shell**。全脚本 30 个 `$(…)` 站点 × 39 文件
≈ **1,170 次 fork ≈ 117s**，占 142s 的大头。

## 被否掉的选项

| 选项 | 为什么没选 |
|---|---|
| 把 0008 的批量化再做一遍 | **段 1/2/6/8/9 已经批量化过了**（`xrun awk` 一次扫全部）。剩余热点是 `fmq`/`grep`/`basename` 这类**小命令**，批量化收益低、反而增复杂度 |
| 继续抬高 `LINT_SECONDS` | **掩盖问题**，且 300s 已接近最差观测值的 1.5 倍，没有余量可抬 |
| 改判据来减少检查项 | **判据变更需 owner + 双签**（人审关卡），且性能不是正确性问题——为快而删检查是本末倒置 |
| 换 `date` 的实现（`to_epoch` 每次跑两次 `date`，BSD 失败再试 GNU） | 确认是最大单点浪费，但改 `keel-lint.sh` 触发硬约束 1（须同步 §9.3），需独立一轮 |

## 后果

- **好处**：性能问题从"未知"变成"已量化"。`budget.env` 的依据可以改成实测区间而非拍脑袋；
  后人优化时**知道该往哪看**（段 3/4/10/11 的 per-file 小命令），而不是瞎试。
- **代价 1**：本 ADR **不降低耗时**——只解释它。真正的优化（换 `to_epoch`、
  `basename` 替 `${f##*/}`）被显式推迟。
- **代价 2**：`LINT_SECONDS=300` 保持不变，**最差采样 201s 只剩 1.5 倍余量**——
  若某天文档数翻倍，它会先于正确性问题报警。
- **风险**：结论基于**单台 Windows 机器**。Linux CI 约 3–8s，永远不会触发该问题；
  但"fork 昂贵"这个前提在 Linux 不成立，**别把这套结论当跨平台结论用**。

## 后续（同日已落地：142s → 68s）

30 个 `$(纯 shell 函数)` 站点全换成变量传递（`rel_set`/`base_set`/`fmq_set`），
**语义、判据、报错文案一字未改**；另加 `checks/perf-baseline.sh` 让"省了多少"有客观记录。
**实测 142s → 68s（2.1×），余量 1.68× → 4.35×；38/38 自测 + §9.3 逐字一致**——
护栏证明没动语义。

**第三项（批量化段 11）试过并回退**：`ENDFILE` 不受 `skip` 约束 →
**39 个非坑文件误报、真坑一条不报**（方向反了但输出看着合理）。
已登记坑 `awk-enfile-ignores-skip-state`。**3.6s 收益不值得引入误判**——
本 ADR 原则：语义优先于速度。

## 下一步

1. `to_epoch` 改一次 awk 批量算日期（省 ~20s）；
2. 段 11 若要批量化须走"先滤清单再 xargs"，**避开 `ENDFILE` 与过滤共存**。
