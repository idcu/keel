## 症状

改成纯 shell 内存查表后，lint **挂死不退出**，跑 5 分钟无输出。优化前只需 119 秒。

## 根因

`KEEL_NL=$(printf "\n")`——**命令替换剥掉尾部换行**，长度是 **0 而非 1**。于是
`${_rest%%$KEEL_NL*}` 退化成 `%%*`（匹配任意最长前缀），相等判断永不成立 → 原地打转。

## 正解

```bash
KEEL_NL='
'                      # ✅ 单引号里的真实换行，长度 1
```

- 凡把特殊字符当分隔符变量，**立刻断言 `${#VAR}` 等于预期**（0 和 1 差一个数量级）
- 先用 3 行小样本验证循环次数，比整体跑一次快几个数量级
- 任何 `${v%%sep*}` / `${v#*sep}` 循环，`sep` 为空都会病态——**非空断言不是冗余**
- **命令组陷阱**（v3.7.1 实测）：`{…; [ -n "$X" ] && printf…;} > tmp && mv tmp final`
  在 X 为空时组状态=1，`mv` 被静默跳过；把 mv 移出组，或 `[ -z "$X" ] || printf …`，并在原子写后断言最终文件存在。
