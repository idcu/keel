## 本轮完成

- [x] **遵守率补回滚维度**（P0）：初版漏了「放行后被回滚」——lint 自己看不见的那类。
      实测同一假仓：**66.7% → 33.3%，虚高一倍**
- [x] **分母补全**（P0）：守卫原为 `grep ^keel/.*\.md$`，只改代码的提交**完全不进分母**
      （实测：提交一次只改 .py → 记录 0 条）。现拆成「记录全量 / 校验按需」，
      并新增**覆盖率**指标：未检查的提交进分母不进分子，不会伪装成"通过"
- [x] **本仓装上钩子**（P1）：此前 15 次提交从未触发过 pre-commit，指标数据一直是空的。
      现在从下一轮提交开始产生**真实**数据
- [x] **回滚匹配用精确格式** `--grep='^Revert "'`——实测 `-i --grep=revert`
      会把"实现 revert 按钮的功能"误计
- [x] **预算超限率聚合**（P1）：`load-estimate.sh` 每轮写 `load.jsonl`（含 `over=`）
- [x] **install.sh 进 CI**（P1）：空项目 → 装 → 钩子 100755 → 锚点判死 → 补上转绿，
      四步全本地实测过才写进 workflow
- [x] **修一个 P0 假成功**：install.sh 的 lint 校验没验到新装项目（详见坑条目）
- [x] **修 install.sh 吞原因**：不再把 lint 输出丢 `/dev/null`，现打印判死原因
- [x] **修自己引入的回归**：上轮误把项目仓索引覆盖到发布仓，挤掉模板的连接池坑登记
- [x] **修 awk 字符串比较 bug**：峰值永远偏小（字典序比较，详见坑条目）
- [x] 新坑 2 条：awk 字符串比较（P2）、install 验错对象（**P0**）
