# NOW · main

## 当前焦点

**第十五轮：把两句一直只是"描述"的话变成判据——两句各自都盖着别的东西。**
owner 已明确授权（"全部给你授权，按你的分析拍板并全量推进"），
故本轮落地了此前被人审关卡挡住的 ADR 0014，并清掉一条挂了很久的假告警。
上一轮见 [NOW-history/](NOW-history/)（10-04 评估与竞品对比）。

## 本轮完成

- [x] **ADR 0014 落地：「零 stderr 噪声」从形容词变成判据**。此前 `test-lint.py`
      捕获并打印 stderr 却**从不判死**——捕获 ≠ 判死。现为 `NOISE` 元检查
- [x] **判据第一次运行就抓到此前从未见过的噪声**
      （`[SAFE_DELETE_BULK_CONFIRM_REQUIRED]`）——它"从未见过"正因判据从不检查。
      白名单改为**前缀豁免** `SAFE_DELETE_`（同源同因同解，不逐条枚举）；
      **豁免必打印不静默**。独立验过判死能力（真错误确实判死，非橡皮章）
- [x] **蒸馏告警不再报已蒸馏的坑**：段 11 只看 `triggers` 不看 `status`，
      而 §7.4 的流程「triggers≥3 → 提炼 + 置 distilled」**走不到终点**。
      实测只报 `active` 的、不报 `distilled` 的。**那条 ⚠️ 终于消失**
- [x] **顺带修一个判据自曝的计数 bug**：输出曾成 `39/38 例`（分母没跟着变），
      现显式写作 `38 用例 + 1 元检查`
- [x] 39/39 自测 PASS · §9.3 逐字一致 · 两仓 lint 0 fail · **零 ⚠️**
