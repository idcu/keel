# GLOSSARY

> 术语的**唯一真源**（§2 原则 1）：同一个概念只允许一种写法，其他写法都是 bug。
> 本表同时是 `checks/rules.md` 里"术语混用"检查的输入——那条 grep 规则就扫这张表。
> 规格见《Keel 设计稿》§3.2 / §5.3。

## 术语

| 术语（唯一写法） | 禁止写法 | 一句话定义 | 备注 |
|---|---|---|---|
| 规格 / 设计稿 | 规范、文档、说明书、design doc | `DESIGN.md`，Keel 的唯一真源 | 全文只写"规格" |
| 模板 | 骨架、starter、脚手架 | `keel-starter/keel/`，对外分发的纯骨架 | 不含设计稿 |
| 实例 | 副本、复制品、影子 | 本仓根的 `keel/`，Keel 项目自己的上下文基座 | 照模板长，内容独立演进 |
| 漂移 | 不同步、不一致、版本落后 | 规格与脚本、或实例与模板之间该同步而未同步 | `test-lint.sh` 的 DOC 检查守它 |
| 点火 | 接入、锚定、开门 | 在工具规则里放上 §4.1 那一句，让 AI 真的会读 | 不点火 = Keel 不存在 |
| 必读 | 入口、首页、README | `INDEX.md` + 当前 `NOW*.md` | 每次会话的固定成本 |
| 判据 | 规则、检查、lint 规则 | `keel-lint.sh` 里"什么算错"的定义 | 改判据属人审关卡（双签） |
| 闭环 | 写回、强制回写 | 完成任务必须写回 NOW / 登记坑 / 跑 lint | 靠四处钩子，不靠自觉 |
| 单轮加载量 | 上下文量、token 预算、加载预算 | 一次会话读入 Keel 的总字节（`BYTES_SESSION`） | ≈3 字节/token |
| 蒸馏 | 合并、上提、总结 | 坑反复触发后把结论上提为宪法硬约束 | `DISTILL_AT=3` 触发 |

## 什么该进这张表

1. **进**：跨模块反复出现、且已经出现第二种写法的词；领域专有名词。
2. **不进**：只在一个文件里出现的局部命名；从代码一眼能看出的类型名。
3. **上提**：如果某个术语的写法之争反复发生（同一坑被触发 ≥3 次），
   应在 `CONSTITUTION.md` 加一行硬约束，而不是继续往这张表加行——那是 §7.4 的蒸馏。
